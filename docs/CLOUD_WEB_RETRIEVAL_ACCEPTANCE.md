# Cloud Web 正文提取优化验收

日期：2026-10-15。任务 WEB-RETRIEVAL-01，起点7d0312d6。

## 结论

共享HTML提取器已修复一个确定的证据丢失点：导航文字占据模型上下文头部，正文中的
发布日期随后被通用工具头尾截断省略。只修改web_content.py，使用现有stdlib HTMLParser
优先提取可见main或role=main区域。没有主区域或主区域为空时保留原全文回退；多个
主区域按顺序合并，嵌套不重复。正文内的header/time保留，不粗暴删除所有header。
原hidden/aria-hidden/script隔离、内容类型、UTF-8字节上限和artifact权限路径不变。

改动同时作用于legacy Web gateway和调用它的原生HTTP fetch provider。不修改通用
ToolOutputProjector的12000字符预算，不新增依赖、查询改写、网页特例或正文缓存。
HTML语义标记不完善的页面仍可能包含导航；本片没有引入启发式正文识别算法。
