- **清单发布**：v122 新增按部署、Host、连接器、profile revision 索引的追加式发布记录。
  受信运维使用 `scripts/publish_host_manifest.py`，提交经过审核的清单和两个 digest：
  `--expected-current-digest` 防止并发覆盖，`--approved-digest` 固定审核内容。
  参数另有 `--namespace`、`--host`、`--connector`、`--profile-revision`、`--manifest`。
  连接配置取当前 Cloud PostgreSQL 环境，不向用户或普通 Agent 开放发布权限。
  新 Task 按当前发布冻结，旧 Task 按原 digest 读取。连接器、授权版本、撤销检查不变。
  回退可把已审核的旧清单重新发布为当前版本，已引用的新清单仍可读取。
- **授权失败**：脱敏日志区分 401/403 拒绝、其他 HTTP 错误、超时、传输失败、
  响应无效等类别。包含阶段、耗时、安全 HTTP 状态和可用的 UUID 请求标识。
  不输出响应正文、凭据或业务参数；仍失败关闭，不自动重发。历史异常没有新增证据时不归因。
- **按需准备**：对允许延迟的 Cloud 隔离运行，在只读查询中核对 Host 工作区归属及挂载目标。
  构建网关和只读快照上下文不创建目录或确认物理卷就绪。
  首次需要文件系统时由原 DeferredRuntime 准备卷、验证目标及配额、建立运行时，
  并在各边界检查当前租约和取消。已准备的运行时仍遵循原终止/回收路径。
  Git、归档、快照、需要已有沙箱状态、持久胶囊或原生 Web 本地存储的路径继续走保守准备。
