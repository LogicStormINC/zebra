## 原生验证和最小实施

同一实际官方URL，复用真实Worker内同一TLS/公共DNS/无重定向/字节上限传输。
旧Accept返回gzip HTML，解码1692922字节，body322.15ms，总1451.37ms。
声明优先Markdown后服务端返回gzip text/markdown，解码16036字节，body1.19ms，总847.19ms。
保留Published2025-05-01、vector set、八种结构和性能特性；日期由自然语言改为ISO，
不是日期丢失。解码体积减约99.05%，不可据此声称线上压缩传输字节也减少99.05%。
原生单次时序有网络波动，不能作为稳定端到端收益。

生产仅改现有fetch请求的Accept头：text/markdown优先，其余原支持的plain/html/json/xml
均保留q0.9。现有text/*准入和纯文本投影已支持Markdown，无新解析器、依赖、URL改写、
跨源跳转、二次探测或自动重试。服务端不支持时可按原格式返回；若返回406则保持失败，
不暗中多发HTTP。gzip压缩/解码上限、DNS/TLS/取消和来源授权全部保持。
Markdown正文按既有纯文本路径保留，实际抓取source URL仍在typed receipt中；
相关Markdown链接不扩展成新证据元数据，不把任意正文URL授予引用资格。

第一次私有B探针误改了DoH请求的Accept，导致本地探针失败；限定实际目标后重新验证，
原始失败单列invalid-probe。该错误未进入生产源码，不算上游失败或页面样本。
原生公开正文仅保留在私有证据目录，容器/tmp探针文件已清除。
