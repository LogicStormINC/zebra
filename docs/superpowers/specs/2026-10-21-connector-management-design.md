## Decision and reuse

Reuse native HostConnectorProfileVersion/HostConnectorBinding/registry, and B1 current Host approval, mounted configuration and rthm_ service credential. Separate credential+approval service would duplicate the same Host administration boundary; allowing arbitrary endpoint/Profile requests would bypass approved trust. Instead explicitly grant connector.read/connector.write actions and optionally add connectorProfile to the existing private config. Old files/fingerprints/actions stay byte-compatible and do not gain connector permission. Adding/changing template/actions requires a next Host approval revision, fencing old B1/B2 replicas together (document this shared credential/config lifecycle).
