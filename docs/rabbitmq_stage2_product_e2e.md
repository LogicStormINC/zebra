## Defects reproduced and fixed at shared boundaries

1. The Trench mapper swallowed text increments until RUN_FINISHED. It now emits
   increments/reset events, while final answers remain authoritative so published
   download links are not replaced by accumulated plain text.
2. A takeover's new mapper lacked earlier text/tool state. Resume now replays the
   bounded same run; exact cursor-group dedupe prevents duplicate persistence.
3. A 60,000 ms RPC setting fell outside the legacy 30,000 ms maximum and silently
   became 5 seconds. Model idle waiting is now separately bounded (default 120 s),
   and the fixture uses a valid 30 s RPC timeout. RPC validation semantics are not
   otherwise changed.
4. Empty failed/cancelled snapshots became an endless processing placeholder.
   The shared frontend normalizer preserves canonical error details and is stable
   through JSON persistence and repeated normalization.
5. Next's rewrite compression gzipped durable SSE, buffering real increments.
   Shared SSE responses now add `no-transform` while preserving cache directives.
   Normal page compression is unchanged.
