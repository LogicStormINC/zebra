## 能成立的收益

启动段相对更可比：两侧每次模型前都是同类准入/投影准备，但不是完全固定的调度环境。

- click→首模型请求：A 平均 3.508s，B 2.439s，减少 1.068s（30.5%）。
- Worker 开始→首模型请求：1.091s→0.422s，减少 0.670s（61.4%）。
- 该启动段新建有界连接每轮 44→5（减少 88.6%）。非空 execute 378→415，空探测 18→33；连接复用没有带来 SQL 数量下降。
- 首过程说明：A 5.280/4.751s，B 3.509/3.536s；过程文字先于首正文，不能混报为首正文。

四轮原始平均：首正文 30.175→23.474s（低 22.2%），整轮 37.027→27.903s（低 24.6%）。这只是本组观察值，只有每侧两个样本，无显著性或稳定 SLA 结论。A1 对 B2 几乎持平，B1 比 A1 更慢。

整轮 Worker 非空 SQL 平均 3010→2973.5（低 1.2%）；包含空探测的 execute 3029→3118（高 2.9%）。API SQL 1443.5→1291；两个所测 scope 合计非空 SQL 4453.5→4264.5（低 4.2%）。这些变化受模型/工具数和流订阅时长影响，不能归因为同工作量的 SQL 优化。Worker 新建有界连接平均 480.5→233（低 51.5%），同样是不同工作量的描述值。

Worker 除模型和工具区间并集以外的剩余时间：A 3.865/7.085s，B 3.120/2.715s；仍包括存储、编排、等待及观测成本，不是纯 CPU 时间。API effects 轮询次数为 23/28/24/47，每次所测 8 SQL，说明整轮越长，Host 的轮询成本仍在增长；本次不扩展修改轮询架构。
